I. System Philosophy & Architecture

FreeLinX is an ultra-fast, independent operating system built from source without relying on the GNU toolchain, glibc, or systemd. It combines the speed of the Linux 6.6 Kernel with the lightweight precision of Musl libc, LLVM / Clang, NetBSD userland, and Toybox.

Key highlights of this release:

  • Zero GNU Dependencies: Clang + LLVM libc++ / libunwind + Musl. No glibc, no gcc, no coreutils bloat.
  • Self-Hosting C Stack: Built-in native tcc (Tiny C Compiler) and clang. Compile C code directly with zero setup.
  • Native Package Manager: First-party xpkg binary packaging system with fast SQLite3 repository indexing.
  • Custom Filesystem Tools: Dedicated flx-fs high-performance retro file system.
  • Instant Boot & Low Footprint: Cold boots in < 2 seconds and idles at under 35 MB of RAM.

II. Essential Desktop Shortcuts (Qýsayollar)

Control your FreeLinX desktop with lightning speed using these standard key combinations:

Key Combination Action / Target Description
Win + Enter / Win + t Terminal Emulator Launches st / uxterm with UTF-8 support
Win + e flxt Text Editor Opens the 90s Motif/CDE retro text editor with font scaling
Win + f File Manager Launches flx-fm Cairo graphical file manager
Win + w Web Browser Launches Dillo 3.1.1 (or flx-browser)
Alt + Space / Right-Click Root Menu Opens full system menu anywhere on desktop
Alt + Tab Switch Windows Cycles through open application windows
Alt + F4 Close Window Closes current active application window
