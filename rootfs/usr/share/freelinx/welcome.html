Network Controls

To connect to the Internet or manage WiFi:

  • Open Network Manager from the desktop menu (or run flx-netmgr).
  • Or use terminal commands: flx-wifi scan, flx-wifi connect "SSID" "pass".
  • Dynamic DHCP: dhcpcd eth0.
