 1. SYSTEM PHILOSOPHY

FreeLinX is a clean, modern operating system built on top of the Linux kernel without any components from the GNU project. It uses no glibc, no GCC, no GNU coreutils, and no systemd.

  • C Library: Musl libc (strict standards, fast, lightweight).
  • Base Toolchain: LLVM/Clang 21 with lld linker and compiler-rt.
  • Self-Hosting: Native Tiny C Compiler (tcc) and Clang on-board.
  • Userland: NetBSD base utilities, Toybox, and custom FreeLinX tools.
  • Package Manager: xpkg (custom binary package format with SQLite3 repository index).
  • Filesystem: flx-fs custom filesystem engine + ext4/vfat.
  • Init & Services: Lightweight runsv supervision + mdevd device hotplug.
  • Footprint: Cold boot in ~1.5 seconds, base idle RAM consumption < 35 MB.

 2. DESKTOP SHORTCUTS (KEYBINDINGS)
The desktop runs Openbox with a retro CDE/workstation color palette. All primary functions can be driven directly from the keyboard:

Key Combination Action Description
Win + Enter or Win + t Terminal Spawn st / uxterm interactive shell
Win + e Text Editor Launch flxt (90s Motif text editor)
Win + f File Manager Launch flx-fm graphical file browser
Win + w Web Browser Launch dillo graphical browser
Alt + Space Root Menu Open system menu at cursor position
Alt + Tab Cycle Windows Switch focus to next open window
Alt + F4 Close Window Terminate or close the current window
Right-Click on desktop Applications Menu Full list of software, tools and shutdown options

 5. COMMON TERMINAL COMMANDS
Open a terminal (Win+Enter) and run: 
  # Search and install packages via xpkg
  xpkg search <name>
  doas xpkg install <package>

  # Scan and connect to wireless network
  doas flx-wifi

  # Compile a C file with Tiny C Compiler (instant)
  cc hello.c -o hello && ./hello

  # Check active network routes and interfaces
  flx-net
  ifconfig

  # Check running processes
  htop

 6. INSTALLATION TO DISK (BARE-METAL)

FreeLinX includes an automated Bare-Metal GPT + Limine UEFI/BIOS installer. To install this live system permanently onto an SSD, NVMe, or USB drive: 

  doas flx-install

The installer will detect available block storage devices, create GPT partitions, format FAT32 EFI and Ext4 Root, deploy the entire system, and configure the Limine bootloader automatically.
